O padrão de projeto Prototype funciona com base na ideia de clonagem, fazendo a duplicação de arquivos no computador.
Em vez de criar um objeto do zero, o sistema simplesmente localiza um objeto já existente, chamado de protótipo, 
e solicita que ele faça uma cópia exata de si mesmo. 
Para que isso seja possível, o padrão define uma interface comum que obriga o objeto a ter um método de clonagem.
